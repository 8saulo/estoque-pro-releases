# Estoque Pro

Gestão de comércio e estoque para Windows: caixa com leitor de código de barras, controle de estoque com alertas, importação e exportação de planilhas e backup automático. Funciona sem internet.

## Download

**[Baixar a versão mais recente](https://github.com/8saulo/estoque-pro-releases/releases/latest)**: abra a página e clique em `Estoque-Pro-Setup-x.y.z.exe`.

Experimente grátis por 30 dias. Para usar o app é preciso uma conta e uma assinatura, criadas dentro do próprio programa, em **Assinatura**.

## Atualizações

O Estoque Pro procura novas versões sozinho, uma vez por dia. Antes de instalar, ele faz um backup dos seus dados. Você não precisa baixar o instalador de novo.

## "O Windows protegeu o computador"

Se essa tela aparecer na instalação, clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece com programas de editores que o Windows ainda não reconhece.
